# Assignment: Product Card

**Assigned Student:** Astha

## Objective

Create a simple product card for a fictional product using HTML and CSS.

## Requirements

- Product image or placeholder
- Product name
- Short description
- Price display
- Call-to-action button (e.g., "Add to Cart" or "Buy Now")
- Basic styling (card layout, typography, price highlighting, and button styling)

## Technical Requirements

- Use HTML and CSS only.
- Keep HTML and CSS simple and readable.
- Do not use CSS frameworks.
- Use meaningful class names.
- Keep all work inside your assigned folder.

## GitHub Submission

- Create a separate branch.
- Make meaningful commits.
- Push your branch.
- Create a Pull Request to `main`.
- Add a short PR description.
- Respond to review feedback if changes are requested.
