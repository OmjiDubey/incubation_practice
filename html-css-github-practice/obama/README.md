# Assignment: Movie/Book Card

**Assigned Student:** Obama

## Objective

Create a simple movie or book information card using HTML and CSS.

## Requirements

- Cover or poster image (or placeholder)
- Title (movie or book title)
- Author or genre tag/label
- Short description or synopsis
- Rating (e.g., star rating or score badge)
- Action button (e.g., "Watch Trailer", "Read More", or "View Details")
- Basic styling (card layout, poster aspect ratio, badge styling, and button design)

## Technical Requirements

- Use HTML and CSS only.
- Keep HTML and CSS simple and readable.
- Do not use CSS frameworks.
- Use meaningful class names.
- Keep all work inside your assigned folder.

## GitHub Submission

- Create a separate branch.
- Make meaningful commits.
- Push your branch.
- Create a Pull Request to `main`.
- Add a short PR description.
- Respond to review feedback if changes are requested.
