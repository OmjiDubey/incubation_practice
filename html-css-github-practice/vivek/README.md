# Assignment: Food Card

**Assigned Student:** Vivek

## Objective

Create a simple food or restaurant item card using HTML and CSS.

## Requirements

- Food image or placeholder
- Food/dish name
- Short description of the dish
- Price display
- Order button (e.g., "Order Now" or "Add to Order")
- Basic styling (card presentation, image scaling, clean typography, and button styling)

## Technical Requirements

- Use HTML and CSS only.
- Keep HTML and CSS simple and readable.
- Do not use CSS frameworks.
- Use meaningful class names.
- Keep all work inside your assigned folder.

## GitHub Submission

- Create a separate branch.
- Make meaningful commits.
- Push your branch.
- Create a Pull Request to `main`.
- Add a short PR description.
- Respond to review feedback if changes are requested.
